# hobby chess bot

just a simple chess engine that is written in typescript. made me realize how
insufferably slow javascript can get when anything you do is remotely comput-
ationally heavy.

## features

- game draws a board
- checkmate/draws
- FEN string parsing
- legality checking
- board flipping
- board resetting
